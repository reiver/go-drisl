# go-drisl

Package **drisl** provides an implementation of DRISL (Deterministic Representation for Interoperable Structures and Links) used by ATProto, for the Go programming language.

## Documention

Online documentation, which includes examples, can be found at: http://godoc.org/github.com/reiver/go-drisl

[![GoDoc](https://godoc.org/github.com/reiver/go-drisl?status.svg)](https://godoc.org/github.com/reiver/go-drisl)

## Import

To import package **drisl** use `import` code like the follownig:
```
import "github.com/reiver/go-drisl"
```

## Installation

To install package **drisl** do the following:
```
GOPROXY=direct go get https://github.com/reiver/go-drisl
```
